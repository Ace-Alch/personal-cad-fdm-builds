# Personal CAD and FDM Builds: design record

## Purpose

Collect custom parts, fixtures and assemblies with their design and print records.

## Elements

| Element | Documentation boundary |
| :-- | :-- |
| Design requirements | Included in the stated project scope. Implementation details need the corresponding source or design file. |
| Parametric CAD | Included in the stated project scope. Implementation details need the corresponding source or design file. |
| Print preparation | Included in the stated project scope. Implementation details need the corresponding source or design file. |
| Fit check | Included in the stated project scope. Implementation details need the corresponding source or design file. |

## Technical stack

- SolidWorks
- CATIA
- FDM
- Fixtures

## Boundaries

Part numbers, interfaces, versions and measured outcomes must come from the original artifacts. They are not inferred from the project title.

## Decisions to recover

Record each design decision with its problem, selected option, rejected options and supporting artifact. Keep the original model or source revision with the record.
